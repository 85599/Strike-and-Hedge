# Options & Futures Copilot Pro

**Nifty, Bank Nifty, Sensex and F&O-stock call/put ideas with entry, stop-loss, target and exit.**
Live option chain (NSE/BSE) → rule-based signal → optional multi-agent AI desk
(chain / volatility / flow / news analysts → bull vs bear → trader → risk debate → portfolio manager).
Sibling of [Research-Copilot-Pro](https://github.com/85599/Research-Copilot-Pro).

> Educational research tool. **Not investment advice.** Levels are generated by rules and LLM text and can be
> wrong; options can expire worthless and futures can gap through stops.

## What it does

- **Signals tab (no API key needed).** For any underlying it computes PCR, max pain, OI walls, ATM IV, expected
  move, OI buildup, futures basis/buildup, India VIX, RSI/MACD/ATR and scores a bias:
  `BULLISH` / `BEARISH` / `RANGE` / `AVOID`.
- **Concrete trade plans.**
  - Bullish → **BUY CE** (first strike beyond ATM) and **Futures long**
  - Bearish → **BUY PE** and **Futures short**
  - Range → **defined-risk credit spreads** (sell near the OI wall, buy a hedge 2 strikes further). Naked
    option selling is never suggested.
  - Each plan has entry, stop-loss, target, reward/risk, lot size, max loss in ₹, and a written exit rule.
    Option stops/targets come from ATR and OI walls on the underlying, converted to premium through delta.
- **Lot calculator.** Enter capital and risk %; every card shows how many lots fit. If one lot risks more than
  your budget, it says so instead of rounding up.
- **Scanner.** NIFTY, BANKNIFTY, SENSEX, FINNIFTY by default; search any F&O stock and press Enter to add it.
- **Option chain tab.** ±12 strikes around ATM with OI bars, change in OI, IV, LTP, call/put walls.
- **AI desk tab.** The full agent pipeline in the same style as Research-Copilot-Pro. The rule engine's numbers
  are given to the trader; if the AI's entry is far from the live premium (e.g. it mistakes a strike for a
  premium) the rule-engine levels are shown instead, with a warning.
- **Decision log.** Each AI call is scored later against the underlying's move, with a hit/miss flag, and
  lessons feed later runs.

## Quick start

```bash
pip install -r requirements.txt
copy .env.example .env          # Mac/Linux: cp .env.example .env
# Signals work without any key. For the AI desk, paste ONE LLM key into .env
uvicorn server:app --port 8000
```

Open <http://localhost:8000>.

Offline tests (no network, no keys): `python -m pytest tests -q`
UI with synthetic data (no network): `python tests/ui_harness.py` → <http://127.0.0.1:8765>

## API

| Endpoint | Purpose |
|---|---|
| `GET /api/signal/{sym}?expiry=` | rule-based signal, chain rows, futures, VIX |
| `GET /api/scan?symbols=NIFTY,BANKNIFTY` | one-line bias + primary setup per underlying |
| `POST /api/runs`, `GET /api/runs/{id}` | start / poll the AI desk |
| `GET /api/runs/{id}/report` | full markdown report |
| `GET /api/diag/{sym}` | what each price source returns |

## Project layout

```
server.py            FastAPI app
copilot/
  nse.py bse.py      option chain + futures (unofficial endpoints)
  chain.py greeks.py normalise chain, Black-Scholes Greeks / IV
  analytics.py       PCR, max pain, walls, expected move
  signals.py         rule engine: bias + entry / stop / target / exit
  dataflows.py       data packs for the analysts
  agents.py graph.py the AI desk
  market.py          quotes, indices, VIX, history, news
web/                 dashboard (vanilla JS, no build step)
tests/               offline tests + UI harness
```

## Data sources & legal

NSE, BSE and Yahoo endpoints are **unofficial, personal-use only** and can change or block requests without
notice (NSE in particular rate-limits and uses Akamai bot protection). As of Oct 2026 the old
`/api/option-chain-indices` endpoint is retired; this project uses the current
`/api/option-chain-v3` + `/api/option-chain-contract-info` pair and prefers `curl_cffi` (Chrome TLS
fingerprint) to reduce 403s. If the chain still fails to load, open `/api/diag/NIFTY`. Lot sizes in
`copilot/universe.py` are fallbacks; the live lot from the exchange payload is used when present, but SEBI
revises lots, so check them. Publishing buy/sell calls publicly may require SEBI Research Analyst registration.
